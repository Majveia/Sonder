# SONDER

> *sonder (n.): the realisation that every passer-by has a life as vivid and complex as your own.*

A playable, simulated universe in the browser (three.js, no build step). Start at the cosmic web — a live
ΛCDM structure-formation simulation — and fall through a galaxy and a star system down to the streets of
living worlds.

```bash
node tools/serve.cjs 8080     # then open http://localhost:8080/
```

Any static file server works; there is nothing to install or build.

See `CLAUDE.md` for architecture and conventions.
